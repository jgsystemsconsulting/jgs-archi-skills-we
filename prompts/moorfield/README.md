# Sequenced jobs (Moorfield Range)

Paste one job at a time into ZCode. Copy only the fenced block. Specialists
stay orchestrator-dispatched. The orchestrator still stops at the View Plan
gate.

Open `models/moorfield-range.archimate` in Archi. Confirm the model name
**Hawker Range Systems Ltd**. Confirm MCP `get-model-info` is not Hatherley
Plate Ltd. Open a view (or create an empty one) before the first mutate.
File → Save after every passed job.

1. [01-motivation.md](01-motivation.md)
2. [02-capability.md](02-capability.md)
3. [03-operations.md](03-operations.md)
4. [04-application.md](04-application.md)
5. [05-technology-closeout.md](05-technology-closeout.md)

Refuse out-of-scope invention (weapons system, ERP, data lake, work
packages, second site, air-vehicle SysML, RangePlan swallowing AirStack or
GroundOS). Log it. Re-paste the same job.

After each paste, add a row to [record.md](record.md).
